🌌 Visión y Origen del Proyecto

Space Assault v2.0 es un videojuego de combate aeroespacial y arcade táctico creado para revivir la era dorada de los clásicos shoot 'em up (shmups) espaciales, combinado con tecnologías web modernas de alto rendimiento: renderizado nativo a 60 FPS en HTML5 Canvas 2D, síntesis de audio procedural en tiempo real mediante Web Audio API y persistencia en la nube.

El proyecto fue concebido para demostrar que es posible construir una experiencia de juego arcade inmersiva, receptiva y visualmente espectacular directamente en el navegador, sin necesidad de descargas, emuladores ni complementos pesados.

🏛️ Arquitectura de Software y Tecnologías

⚡ Motor Frontend a 60 FPS

Construido en JavaScript Vanilla modular (ES6+), Canvas 2D nativo con física vectorial inercial, detección de colisiones optimizada AABB, efectos de resplandor neón (*bloom*), ondas de choque procedurales y sacudida de pantalla (*screen shake*).

🔊 Síntesis de Sonido Web Audio API

Motor acústico autosuficiente que sintetiza láseres, explosiones y acordes synthwave matemáticamente mediante osciladores, generadores de ruido y filtros pasa-bajos sin requerir archivos de audio externos.

🛡️ Backend Robusto en Python Flask

Servicio RESTful estructurado en Blueprints modulares, autenticación segura basada en tokens JWT con firmas criptográficas HS256 y hashing de contraseñas con PBKDF2.

💾 Persistencia & Ranking Global

Base de datos relacional SQLite gestionada mediante SQLAlchemy ORM, con respaldo automatizado de progresos, desbloqueo de flotas y ranking competitivo en tiempo real.
